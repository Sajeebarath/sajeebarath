## 🚀 Featured Projects

### 🔐 OWASP NodeGoat — Application Security & DevSecOps

Our team used OWASP NodeGoat to investigate vulnerabilities in a training web application.

**My contribution**

- Updated the login flow to issue a fresh session ID after authentication.
- Changed account creation to store salted bcrypt password hashes.
- Retested login behaviour and compared Semgrep findings before and after remediation.

**Tech stack:** `Node.js` `Express` `MongoDB` `bcrypt` `Semgrep` `GitHub Actions`

[View the NodeGoat team repository](https://github.com/prabhawathi-b/ie3142-devsecops-nodegoat)

### 🌐 Banking Network Security — Access Control Testing

Our team modelled a banking network with guest, branch, core banking and payment-partner segments.

**My contribution**

- Configured extended access control lists to restrict guest and branch access to the simulated payment partner.
- Verified the guest restriction with a before-and-after ping test. The guest PC received four replies before the change and zero afterwards.
- Configured Dynamic ARP Inspection on the core banking VLAN and checked that legitimate traffic still passed.

**Tools & concepts:** `Cisco Packet Tracer` `VLANs` `Extended ACLs` `Dynamic ARP Inspection`

[View the before-and-after test evidence in my portfolio](https://sajeebarath.github.io/portfolio/#projects)

### 🔎 CipherNest CTF — Digital Forensics & Network Analysis

Our team built a six-stage capture-the-flag challenge. I developed the two stages
where participants investigate evidence from a simulated incident.

**My contribution**

- **Stage 4 · Buried Logs** — Designed a forensic challenge around recovering deleted evidence from a binary file.
- **Stage 5 · Whispers on the Wire** — Designed a Wireshark challenge where participants identify credentials transmitted in cleartext in an FTP capture.

**Tools & concepts:** `Wireshark` `FTP` `Packet Analysis` `Digital Forensics` `Docker`

[View the CipherNest team repository](https://github.com/prabhawathi-b/CipherNest_CTFbox)

### 🍄 Mushroom Data Analysis — Machine Learning

Our team explored the UCI Secondary Mushroom Dataset and prepared its features
for classifying mushrooms as edible or poisonous.

**My contribution**

- Applied Principal Component Analysis (PCA) to reduce the dimensionality of the preprocessed data.
- Examined explained variance and visualised the samples using the first two principal components.

**Tech stack:** `Python` `Jupyter Notebook` `scikit-learn` `PCA`

[View the machine learning team repository](https://github.com/IT24103888/2025-Y2-S1-MLB-B1G1-09)
